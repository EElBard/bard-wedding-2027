Connect Free Neon Postgres to Go Live

Your dashboard and RSVP forms are wired to /api/rsvps, and no database connection string is configured yet. To enable persistent storage on Vercel for free (no credit card required):

  1. Open your project in Vercel Dashboard → Storage → Create Database → Neon (Serverless Postgres).
  2. Link the database to this project (Vercel automatically populates DATABASE_URL).
  3. Redeploy once — the rsvps table initializes automatically on the first request.
